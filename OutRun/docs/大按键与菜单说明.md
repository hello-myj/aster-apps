# 0.2.3 虚拟按键与游戏菜单

## 设备上的操作

- 地图选择：点左右大箭头切换 CIRCUIT 01–15，点 START RACE 开始。
- 驾驶：左下 < / > 为方向，右下 BRAKE 为制动。方向按钮84×64，刹车96×64；绘制与触摸范围使用同一份布局。
- AUTO GAS 自动加速；切换 MANUAL 后出现独立 GAS 按钮。
- 右上 MENU 暂停游戏：RESUME 继续、RESTART 重开当前地图、SELECT MAP 返回当前地图的选择界面。
- 比赛结束可点 RETRY RACE 重试，也可通过 MENU → SELECT MAP 换图。
- 电脑键盘：Esc 打开/关闭菜单；菜单内上下选项、Enter 确认；地图界面左右切图、Enter 开始。

## 实现说明

布局统一定义在 src/port/ui.h；触摸不再把整个画面左右半区解释为驾驶操作。选择/菜单操作会等待该手势松手，避免关菜单或起跑后误触方向。打开菜单会清除触摸和键盘保持状态，恢复时重置帧时钟，不补算暂停期间的物理时间。

暂停菜单无变化时不重复重画；收到菜单选择或恢复事件后才绘制。APP 生命周期暂停/恢复保留菜单状态。返回选图会结束本次比赛、停止并卸载音效，保留当前地图作为选择起点；重开从当前地图起跑。

game_reset_map 统一初始化地图、阶段、交通车及倒计时，避免原先换图时先重复加载 Map1。地图文件和外部资源格式没有变化。
