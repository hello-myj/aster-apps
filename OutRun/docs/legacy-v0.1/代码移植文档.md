# OutRun → Aster 4 代码移植记录

## 上游和实现映射

- 上游：本地 `vendor/upstream（相对当前项目根目录，原为 ../OutRun-upstream）`，ZgzInfinity/OutRun commit `6882721c99bc79365f815f68d389bf5078129e68`。
- `src/main.c`：新写的 Aster ABI 4 单文件应用。使用 SDK `aster_app_init/event/resume/stop/destroy` 生命周期、graphics 命令、surface、filesystem、touch 和日志接口；不编译上游 SFML/C++ 源码。
- `tools/prepare_assets.py`：新写的可重复转换器；从 `Resources/Maps/MapLevels/Map1/map.txt` 提取 `START_RELIEF` 直到 `SPRITES`，生成采样曲率；把上游 Ferrari、TrafficCar1、Map1 棕榈裁剪/缩放，并制作控件图标。生成 `sdcard/.../data/resources/`、根 `resources/` 的打包回退资源及 `resources.json` 来源清单。
- `tools/build.ps1`、`tools/run-sim.ps1`：新建构建/verify 及 ABI 4 模拟器启动脚本。
- `LICENSE`：保留上游 GPL-3.0 文本。

## 玩法、坐标与输入

道路取 Map1 真实曲率曲线数据，2048 个 signed-byte 样本循环组成道路中心线偏移，透视投影成连续道路多边形；道路段具有弯道和路肩。玩家自动加速，触摸屏幕下方左侧控件左/右半分别转向，右侧控件刹车；触摸下方控件外则以左右屏幕半边转向。单触点无法同时制动和转向。离开道路时减速。交通车与玩家距离 `<34` 且横向差 `<0.28` 时发生碰撞，速度下降并置碰撞反馈；该判断使用交通车的实际纵向距离和 lane 坐标。

固定步长模拟累计事件时间，步进频率 30 Hz，每次事件最多补 3 步并将单次 dt 限制到 100 ms。渲染 surface 读取实际尺寸，480×320 布局在模拟器通过。按钮用带透明度绘制覆盖层，控件在画面底部。

## 构建与模拟器验证

环境：Aster SDK 4.0.0、ABI 4.0、SDK 自带 simulator 0.2.0、Node v24.14.0、Windows x64。执行命令：

```powershell
./tools/build.ps1
./tools/run-sim.ps1 --headless --frames 300 --diagnostics ./artifacts/final-diagnostics.json --screenshot ./artifacts/drive-final.png
```

最终构建生成 14,926 B WASM、27,560 B Xtensa AOT、6 个资源，`dist/xtensa/aster.outrun.ast` 为 60,544 B；AOT build、verify 均退出码 0，包未签名。Windows SDK Python 包装器在 stdout reader 线程输出过一个 UnicodeDecodeError traceback，但构建产物完整并由 `aster.exe verify` 报 OK；原始输出保存在 `artifacts/build-verify.log`。模拟器运行包内 WASM，忽略 AOT。

最终外置资源运行 300 帧/presents，exit 0、errors 0；init 日志为 `480x320 Map1 sections=33 resources=external`。`artifacts/final-diagnostics.json` 记录平均宿主帧执行约 31.5 ms、最大 40.2 ms、host allocation peak 307,264 B。`artifacts/external-run.log` 保存真实控制台日志。该时间不是设备帧率。

输入场景定义于 `artifacts/drive-input.json`，触控日志 `artifacts/replay-run.log` 可见 `steer=-100`、`steer=100`、release、`brake=1` 和 release；480 帧/presents，exit 0、errors 0。回放 CLI 不支持 `--state`，因此该场景验证的是包内 `/assets` 回退，启动时 `/data` 查询出现 ENOENT 后转为 `resources=bundled`；对应诊断为 `artifacts/replay-final-diagnostics.json`。`artifacts/collision-replay.json` 与 `collision-diagnostics.json` 记录无输入连续驾驶/碰撞结果。最终外置资源运行记录 `resources=external` 及 4 次碰撞。截图为 `artifacts/drive-final.png`。

## 内存参数与估算

manifest：`initial_memory=1048576`、`max_memory=2097152`、`heap=524288`、`stack=16384` 字节。一个 480×320 RGB565 surface 307,200 B；五张解码 RGB565 图约 27 KiB；曲率表 2,048 B、绘图 ring 约 6 KiB、arena 约 1 KiB。估算未计入运行时结构和 SDK 其他分配，不能以 PSRAM 标称容量推导 APP 可用 RAM。模拟器 `guestPeakBytes=1048576` 是 guest memory 页统计。

## 已迁移与未迁移

**已迁移/本首版实现**：上游 Map1 曲率数据驱动的伪 3D 道路；上游玩家、交通车与棕榈图像；自动油门、左/右转、单触点刹车、路外减速、交通车、基于位置/距离的碰撞；基本速度和碰撞 HUD；透明虚拟控制；外置 SD 资源和包内回退；可重复转换/构建/模拟器运行。

**未迁移**：原版完整三维道路与高度模型、其余地图及分支路线、原始驾驶/AI/碰撞模型、关卡计时计分和菜单、道具/动画、原版音效音乐、配置持久化、多点触控及设备侧性能验证。现有碰撞和物理为首版简化实现，不是逐语句移植上游逻辑。
