# Pixel Wheels 实机部署记录

日期：2026-10-23（北京时间）。

## 设备与构建

微雪 waveshare35b，ESP32-S3、240MHz 双核、8MiB PSRAM、16MiB Flash。固件公开 ABI 4.1.0；SD 已挂载，部署前剩余约714MB。通过已共享 USB 串口经 WSL /dev/ttyACM0 传输。本次不烧录固件。

APP 版本0.1.1，Xtensa AOT，480×320横屏。包125,044 B，WASM41,905 B，AOT75,544 B，图标6,928 B。Guest初始内存3MiB、上限4MiB；实际运行峰值以设备日志为准。

## 资源

原模拟器资源从 sdcard 目录读取，设备资源由 tools/prepare_device_assets.py 另生成至 dist/device-resources。20个资源共19,345,460 B，其中地图、车身、图标、音效保持现有格式，音乐完整转为128kbps / 44.1kHz / 双声道MP3。所有单文件小于4MiB。转换后的音乐分别为country 3,841,924 B、city 2,909,875 B、snow 2,821,268 B。

实际部署路径：/SD:/aster/apps/aster.pixelwheels/data/resources；APP沙箱使用/data/resources。上传逐文件 CRC 校验，断点状态保存在artifacts/device/upload-status.json；部署详情见deploy.log。

## 本次实机适配

- 必需能力补齐audio-out/audio-effects，符合ABI4.1新音效导入的公开约定。
- 保持地图、渲染分辨率、15车型与触点slot输入；没有改固件协议。
- 每60个实际驾驶绘制帧输出PW PERF，elapsed_ms为窗口墙钟时长，draw_ms为绘图+present累计时间，非完整CPU耗时。60*1000/elapsed_ms用于该窗口实际绘制帧率；请求30Hz不等于真机达到30FPS。
- 安装与启动完成情况以artifacts/device/deploy.log及后续实机截图为准，本文的预备参数不能替代运行结果。
## 安装与启动结果

20项资源和125,044B应用包均上传成功并通过传输CRC。原生安装器返回installed OK，随后以AOT启动，状态RUNNING (err=0 starts=1)。窗口日志确认landscape / 480×320，首张country地图751,896B已加载。实机截图保存在artifacts/device/first-screen.png；截图接口导出的是面板原始320×480像素，内容已由APP横屏旋转显示。

启动约40秒时，设备app stats的peak字段为4,521,984B（约4.31MiB），原始值记录于runtime.log。Guest初始/上限配置仍分别为3MiB/4MiB；这些字段应按设备统计口径分别报告，不能把模拟器Guest峰值直接当作真机总占用。系统外部堆最大连续空闲块至少2MiB，APP继续运行，没有本次启动失败或trap证据。

固件仍周期性报告AXS15231B invalid touch frames (-22)，该警告在本APP启动前已存在。横屏画面、音乐人耳试听、双指同时输入和驾驶帧率需结合用户操作及driving.log进一步确认；不能仅凭APP持续RUNNING就认定这些交互已验收。
## 0.1.2 音频版实机更新（2026-10-23）

已安装143,200 B应用包，包含WASM46,854 B和Xtensa AOT88,752 B。资源清单32项，共19,542,457 B；未变更文件复用此前已CRC验证的上传，新增/变更文件全部上传并CRC通过。三首音乐保持完整时长并采用模拟器相同的-9dB平衡；五段引擎、漂移、涉水、碰撞、拾取、涡轮等音频资源已同步到SD。

安装返回installed OK，启动日志明确AOT、landscape / 480×320，country地图751,896 B加载成功。启动32秒时状态RUNNING (err=0 starts=1)，统计peak=4,521,984 B。菜单截图artifacts/device/audio-0.1.2-screen.png已保存，截图仍为面板原始320×480方向。实机驾驶和声音听感待用户操作确认，未把菜单运行状态或请求fps=30当作驾驶性能验收。
