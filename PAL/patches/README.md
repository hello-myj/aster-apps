# 上游兼容补丁

engine-aster.patch 基于引擎 795fc8ae9133b020855f4ef5d44abef23b5f0fce，保存七个引擎文件的完整 Aster 兼容修改，包括入口/退出、原生 UI 字体度量、固定常驻资源构建，以及 P4 独立文字层的文字、菜单备份和动画重绘挂钩。sdlpal-aster 快照已包含该补丁，当前构建不需要再次应用；已对固定上游文件执行 apply --check。

自有适配与此次 ABI、资源路径、显示及触摸迁移代码在 ../port 和 ../tools。升级引擎时先保留快照差异，校验补丁与原始数据重建，再分别执行模拟回归及实机验证。
