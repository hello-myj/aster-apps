# 2026-10-26 模拟器验证

环境：Windows 本地 Aster ABI 4.2 模拟器，480×320，执行 WASM，无 Xtensa AOT。源代码基准见 `vendor/UPSTREAM.json`。

- SDK 编译、转换、打包和最终 verify 通过，最终导入均为公开 Aster API，无 WASI / SDL / Asyncify Host 导入。
- 全部 41 首原曲通过原 LDS/OPL 合成器离线转换；38 个普通音效/语音 WAV 共 794118 字节，另生成圣诞语音对应版本，全部音效满足公开 API 的大小限制。
- 原版主菜单、四章选择、完整游戏商店、关卡确认、第一关手动战斗已实际运行。
- 浏览器实际键盘输入验证了选择、方向移动、射击、P 暂停及恢复。手动模式的失焦自动暂停问题已修复。
- 写出了原版 `tyrian.sav`，重启能读取，资源目录与存档目录分离。
- 从原版主菜单 Quit 正常结束，退出码 0；同时写出 `opentyrian.cfg` 和 `tyrian.cfg`。
- 无头模拟器运行 2400 次回调，约 91 秒，进入 Demo 战斗，退出码 0、trap=null、1216 次画面提交。战斗段日志约每 5 秒 110 帧，即约 22 FPS。
- 游戏自有堆峰值 1621648 字节，约 1.55 MiB；线性内存固定 4 MiB。模拟器表面分配峰值 307264 字节，不能据此推算设备所有音频与固件占用。
- 最后仅补充了对已有 `/data` 根目录 mkdir 的 POSIX EEXIST 返回，重新构建校验并运行 600 回调启动检查。

日志与诊断保存在忽略入库的 `artifacts`。音乐/音效已验证资源生成和播放 API 调用，尚未由真人确认听感、混音平衡或循环接点。触摸布局和多指合并已实现，当前没有实机触摸验收。

没有烧录开发板，没有生成或验证本项目的 Xtensa AOT，没有测得实机 FPS。未逐关通关全部四章，未完成长期游戏/保存加载矩阵测试。

首次运行缺少用户配置/存档会回退到原版默认设置；数据为 Tyrian 2.1 四章，探测不到第五章和自定义 `newsh$.shp` 是预期行为。
