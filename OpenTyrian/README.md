# OpenTyrian for Aster

穿过星海与弹雨，重返像素银河。

基于 OpenTyrian 原版 C 引擎的 Aster 模拟器移植。原引擎的菜单、四章数据、飞船商店、关卡、敌人、武器和演示逻辑直接编译运行。首版针对微雪横屏 480×320，尚未部署或测量实机性能。

## 试玩

先点击模拟器的「启用声音」，再点击游戏屏幕使键盘获得焦点。

- 方向键或 WASD：移动、选择菜单。
- 空格或 Z：射击。
- Enter 或 X：确认菜单、切换前后武器。
- 左 Ctrl / C、左 Alt / V：两侧僚机。
- P：原版暂停；Esc：返回或退出确认。
- 左下圆形摇杆支持八方向，中心有死区；手指拖出底座后仍保持捕获，抬起归中。持续推向一个方向可滚动菜单。
- 右侧「射击」「确认」和「左翼」「右翼」，右上「暂停」「返回」对应上述按键。可一指推摇杆、另一指持续射击。

完整游戏的开局流程：开始游戏 → 单人完整模式 → 第一章：逃离 → 选择难度 → 整备菜单的「进入下一关」→「泰瑞安」→ 确认。也可以在主菜单选择「自动演示」。摇杆上下选择，右侧「确认」推进页面；菜单转场后再确认下一步。

0.1.1 已接入 92 条常用菜单/提示的中文翻译和中文虚拟按键。品牌图案、剧情、帮助正文、装备描述及部分动态文字仍保留原文，尚未完成全量汉化。字体是 Noto Sans CJK SC 2.004 的精简位图子集，字体数据遵循 SIL OFL 1.1，完整许可在 `vendor/licenses/Noto-OFL.txt`。

游戏本身是纵向卷轴射击，原画面为 320×200 横向画布，右侧保留原版状态栏。当前以最近邻显示在 480×300 区域，透明按键覆盖在游戏上；没有强行裁成竖屏。

## 构建与资源

项目完全放在 `APPS/OpenTyrian` 内。SDK 单独安装在相邻的 `aster-sdk`；需要支持 ABI 4.2 内存音效的 SDK/模拟器。Windows 构建需要 Python 3.11+；图标转换需要 Pillow。音频预生成需要 WSL Ubuntu、gcc、SDL2 开发头文件和 ffmpeg。

首次准备：

```powershell
python tools/prepare.py
# 首次重建字体子集或修改 assets/zh-cn.json 后执行；常规构建可使用已入库的生成文件：
python tools/prepare_ui.py
# WSL 中安装对应发行版的 gcc、libsdl2-dev、ffmpeg 后执行：
wsl -d Ubuntu-22.04 -- bash -lc 'cd "/mnt/e/个人项目资料/aster/APPS/OpenTyrian" && python3 tools/prepare_audio.py'
python tools/build.py
./tools/run-sim.ps1
```

WSL 示例路径需随本机项目位置调整。`prepare.py` 对工具链依赖和官方 Tyrian 2.1 数据验证固定 SHA256，保留数据原许可；`prepare_audio.py` 调用原 LDS/OPL 合成器生成全部 41 首音乐，并解码原版音效和两套语音。

`build.py` 先通过 SDK 编译 C，再用 Binaryen 将协程控制和内部 C 栈访问转换为普通 WASM，最后用 SDK 正常打包、校验。中间模块包含编译期导入，会被 SDK 校验拒绝，这是中间阶段；最终包必须重新通过原有校验，导入仅有公开 Aster API。本项目没有改动 SDK、模拟器或固件。

输出包：`dist/xtensa/aster.opentyrian.ast`。此版本没有 Xtensa AOT。外部资源在 `sdcard/aster/apps/aster.opentyrian/data/`，包含 resources、audio、存档与配置。生成资源约 34 MiB，配置与存档在同一 data 目录。仅复制 AST 包无法运行。

## 内存与适配边界

WASM 线性内存固定 4 MiB，不调用 memory.grow。其中包含游戏静态数据、2.25 MiB 自有堆、256 KiB 引擎 C 栈、64 KiB 协程局部变量区、64 KiB 回调 C 栈和 SDK 对象堆；这些是 4 MiB 内部的分配，不要重复相加。模拟器报告的宿主音频解码/混音资源不等于 ESP32 固件的音频占用，实机预算还要包含运行时、代码及固件。

原引擎使用嵌套等待循环。适配层通过 Asyncify 协作暂停，保留引擎自己的 C 栈，Host 的输入/绘图回调使用另一块 C 栈。原游戏计时保持约 69.5 Hz；显示每个 Host 回调最多提交一次。

音频保留原曲和原音效，音乐由原合成器离线生成 MP3，38 个普通音效/语音约 776 KiB，启动时预读。受当前公开接口限制，音效最多四路，同一缓存音效重复播放会重触发；原版为八路。音乐按完整合成段重播，循环接点、原版独立音乐音量和渐弱尚未对齐；`fade_song` 当前即时暂停。此首版不声称音频完全等同桌面原版。

网络对战、桌面手柄、鼠标飞行和其他分辨率的触摸布局未实现。摇杆目前映射原版八方向数字键，不改变原版速度或添加模拟量速度。原版图形设置中的桌面窗口/缩放选择没有实际平台效果。原版单机战斗路径保留；四章内容没有逐关通关验收。
